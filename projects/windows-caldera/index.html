Caldera / Sandcat — Windows

Обезличенный кейс из учебного расследования. Факты отделены от предположений.

GitHub README ↗

Цель

Разобрать подозрительные события создания процессов на двух Windows-хостах учебного стенда.

Наблюдения

В Wazuh обнаружены события с кодированным PowerShell и родительскими процессами, связанными с Sandcat. Расшифрованные команды относились к Process Discovery. Сопоставление процессов и временных меток позволило построить таймлайн.

Оценка и ограничения

Идентификация Caldera/Sandcat оценена с высокой уверенностью. По одним скриншотам нельзя установить, были ли действия согласованными учениями. Доказательств кражи учётных данных, бокового перемещения или эксфильтрации в предоставленных материалах нет.
