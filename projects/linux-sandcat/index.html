Sandcat Delivery — Linux

Обезличенный кейс из учебного расследования. Факты отделены от предположений.

GitHub README ↗

Цель

Проверить телеметрию Linux на признаки попытки доставки агента Sandcat.

Наблюдения

Отчёт содержит четыре события запуска curl с характерными заголовками запроса. Первые два выполнялись с euid обычного пользователя, последующие — с euid 0. Login UID оставался неизменным.

Оценка и ограничения

Наблюдается попытка доставки. Успешная загрузка, запуск бинарного файла и установленный C2-канал не подтверждены: в скриншотах отсутствовали дополнительные аргументы, события запуска и сетевая телеметрия.
