## Evidence and publication
These are sanitized summaries of user-supplied authorized course reports, not claims of production incident response. The new Secure Enterprise Network case study uses authorized lab evidence; its binary screenshots and Packet Tracer file are distributed separately in the downloadable review package until repository upload is confirmed. Other original reports, credential guesses and unrelated sensitive material are not published. Conclusions distinguish observed evidence from hypotheses and unknowns. The owner confirmed publication permission for the Secure Enterprise Network materials.
